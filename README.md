# Data Cleaning and Preparation

Use this folder to document the cleaning steps actually applied to the dataset.

Suggested checklist:
- [ ] Inspect worksheet names, column names, and data types.
- [ ] Check missing values and decide how each field should be handled.
- [ ] Check and document duplicate records.
- [ ] Standardize state, fuel type, vehicle category, and service-type labels where necessary.
- [ ] Validate date, quantity, sales, and service-cost fields.
- [ ] Record any rows removed or values transformed.
- [ ] Refresh the Power BI report and validate key totals against the source data.

**Important:** This checklist is a template. Mark an item complete only after carrying out and verifying that step.
